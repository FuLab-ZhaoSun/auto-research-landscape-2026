# 调研方法

## 时间窗口

本轮更新（2026-11-18）以 **2026-05-18 到 2026-11-18** 为滚动维护窗口；上一版窗口为 2025-12-02 到 2026-06-02。
一个项目可以创建很早，只要在窗口内有以下任一证据，就可以纳入：

- GitHub 最近提交在窗口内。
- release 或 tag 在窗口内。
- README、文档、新闻区有窗口内更新。
- GitHub commit Atom feed 显示窗口内更新。
- 顶刊或顶会论文在窗口内发表，且对应代码或系统仍可访问。

## 纳入标准

项目必须与以下至少一类直接相关：

- 自动科学发现。
- 自动科研实验、数据分析或科研代码生成。
- AI scientist、co-scientist、多智能体科研系统。
- 自动论文写作、文献综述、引用核查、图表生成。
- 自动科研 agent 评测基准。

## 不纳入主表的情况

- 只是通用聊天机器人或通用 RAG，不面向科研流程。
- 超过半年没有维护证据。
- 只有新闻稿、没有可核验仓库或论文链接。
- 仅作为商业产品宣传，无法确认代码或方法。

## 证据等级

- **A**：顶刊/顶会论文或大型机构技术报告 + 代码/系统可访问。
- **B**：活跃开源仓库 + arXiv/preprint/benchmark。
- **C**：活跃开源仓库，但外部评测或同行评审不足。
- **D**：背景项目，重要但不满足半年维护标准或代码不开源。

## 本轮增量范围

- 新增项目的窗口为 **2026-06-02 到 2026-11-18**，即上一版截止日之后的增量。
- 上一版已收录、但最近提交早于 2026-05-18 的里程碑项目保留在主表，并以 `*` 标注，日期不影响其历史价值。
- 所有项目的「最近维护」均用 GitHub API 核对到默认分支最后一次提交，论文链接逐个验证可达性。

## 数据来源

主要来源包括：

- GitHub 仓库 README、commit history、release/tag、Atom feed。
- Nature、Nature Methods、ICLR、arXiv、项目主页。
- 项目官方文档和博客。

本仓库中的日期为调研时可见信息，不保证后续不变。
